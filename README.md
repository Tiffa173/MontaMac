## 🚀 Getting Started

MontaMac is a free, open-source application for macOS that lets you mount FTP, SFTP, and WebDAV remote drives directly in Finder. You can access your remote files just like local ones.

### What You Need

- A Mac running macOS 11.0 (Big Sur) or later
- An internet connection
- Login credentials for your remote server (FTP, SFTP, or WebDAV)

4. Drag MontaMac to your Applications folder
5. Open MontaMac from your Applications folder

## 🖥️ How to Use

1. Launch MontaMac from Applications
2. Click "Add Connection"
3. Select protocol (FTP, SFTP, or WebDAV)
4. Enter server details (hostname, username, password)
5. Click "Mount"
6. Your remote drive appears in Finder

## 🔒 Security

MontaMac uses secure connections for SFTP and WebDAV. Your passwords are stored in your Mac's keychain. The application is open-source, so anyone can inspect the code for security.

## ❓ Troubleshooting

If you encounter issues:
- Ensure you have macOS 11.0 or later
- Check the server address and credentials
- Try a different protocol (e.g., use SFTP instead of FTP)
- Restart the application

## 📝 Notes for Beginners

- FTP and SFTP are methods to transfer files to your Mac from a remote computer
- WebDAV works like a network drive
- The app runs in your menu bar
